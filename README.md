# 🏋️‍♂️ neoApp

## 📌 Descripción
**neoApp** es un proyecto educativo enfocado en la gestión de suscripciones de un gimnasio, integrando análisis de datos con un stack tecnológico moderno.

La aplicación combina:
- 🐍 Python para análisis de datos
- ⚛️ React para el frontend
- ☕ Spring Boot para el backend

El objetivo es construir una solución completa que permita gestionar clientes, suscripciones y generar insights a partir de los datos.

---

## 🚀 Características
- 👥 Gestión de usuarios  
- 💳 Administración de suscripciones  
- 📊 Análisis de datos  
- 📈 Reportes y visualización  
- 🔗 Integración entre frontend, backend y análisis

## 🛠️ Instalación

### Clonar repositorio
```bash
git clone https://github.com/tu-usuario/neoApp.git
cd neoApp
```

### Backend
```bash
cd backend
./mvnw spring-boot:run
```

### Frontend
```bash
cd frontend
npm install
npm start
```

### Python (Data)
```bash
cd data
pip install -r requirements.txt
python main.py
```
